Keep or undo every change Claude makes, one at a time.

A VS Code extension for Claude Code. Every file Claude edits gets Copilot-style review: green for what it added, red for what it removed, and Keep or Undo on each change. Claude writes to disk as usual; you review when you're ready.

In the editor

What it covers

Every way Claude changes a file

Edits and shell commands
Edit, Write, MultiEdit and notebook edits, plus shell commands: the folders a command can touch are snapshotted before it runs and compared afterwards.
Your edits stay yours
What you type in a file under review, outside Claude's changes, is kept automatically. A file you save while a command runs isn't blamed on Claude.
Claude hears about it
Your next message tells Claude which changes you undid, so it doesn't quietly put them back.
Grouped by prompt
See which of your messages produced each change, open one prompt's diff, or keep and undo a whole prompt at once.
Ask Claude about a change
Send one change back to Claude Code with its location and the original code already filled in, in the session that made it.
New, deleted and binary files
A file Claude created can be kept or deleted; a file it removed can be restored. Large and binary files are handled as a whole.
How it works

A baseline for every file Claude touches

  1. Claude edits a file

    A Claude Code hook saves the file's content from before that first edit, its baseline, to ~/.cc-review.

  2. The extension compares

    VS Code diffs the baseline against the file and draws each difference as a change.

  3. You decide

    Keep moves a change into the baseline. Undo puts the original lines back into the file.

  4. The file leaves the list

    Once the file matches its baseline again, there's nothing left to review.

The whole model in one rule: a file is pending as long as it differs from its baseline. That's why a git checkout, a Claude Code rewind or changing the lines back by hand all clear it too.

Install

Three steps, about five minutes

You need VS Code 1.140 or later (the regular release, not Insiders), Node.js and Claude Code.

  1. Build and install the extension

    git clone https://github.com/JiachengZhao98/keep-undo-for-claude-code.git
cd keep-undo-for-claude-code/cc-review
npm install
npm run package
code --install-extension cc-review-0.3.0.vsix

  2. Allow the inline red lines

    Run Preferences: Configure Runtime Arguments, add this line to argv.json, then quit and reopen VS Code. Without it, deleted lines show on hover instead.

    "enable-proposed-api": ["local.cc-review"]

  3. Install the hooks

    The extension offers this on first start, or run Claude Review: Install Claude Code Hooks. You see the exact change to ~/.claude/settings.json before anything is written, and the original is backed up.
